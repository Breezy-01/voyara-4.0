# Voyara App Prototype

This folder contains the approved Voyara mobile app prototype from `voyara-main.zip`.

- `index.html` mirrors `prototype/prototype.html` from the supplied app archive and is the complete interactive phone prototype served at `/app/`.
- The responsive tablet experience remains available separately at `/app2/`.
- The app design must remain unchanged while its authentication and stored prototype data move to the shared Supabase backend.
- Legacy production source and database migrations are reviewed before adoption rather than copied into the live schema blindly.
